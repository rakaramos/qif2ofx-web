QIF to OFX

Convert a QIF statement (for example a Wise export) to OFX 1.0.2. The conversion runs in your browser. Your file is not uploaded.

Options

DatePayeeMemoAmount

Notes
  • Wise exports one statement per currency. Convert each file on its own and set its currency.
  • QIF has no transaction IDs. Each ID is a hash of date, amount, payee and memo, so importing the same file twice gives no duplicates.
  • Auto date format uses day first when every date is ambiguous (like 03/04). Pick Month/Day/Year if your file uses US dates.
  • Categories and splits have no place in an OFX bank statement, so the converter drops them.
